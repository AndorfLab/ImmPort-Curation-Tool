# ImmPort Curation Tool
This tool was developed to support the generation of the [ImmPort repository’s]( https://immport.org/shared/home) *Lab Tests* and *Assessments* templates. Featuring a user-friendly graphical interface, it automates the mapping of study variables using ImmPort files, study-specific data, and a curated data dictionary. By streamlining the submission process, the tool enhances data quality, reduces contributor burden, and improves the reusability of datasets within ImmPort.

## *Assessments* Template
The [*Assessments*](https://docs.immport.org/datasubmission/templatedocumentation/templates/assessments/) template captures non-sample-based information typically recorded in Case Report Forms (CRFs). This includes answers to questions or assessments conducted during study visits. Examples of data appropriate for this template include:
- Medical history
- Physical examinations
- Vital signs

## *Lab Tests* Template
The [*Lab Tests*](https://docs.immport.org/datasubmission/templatedocumentation/templates/labtests/) template is designed for sample-based data collected during the study. This includes laboratory measurements and analyses performed on biological specimens. Examples of data suitable for this template include:
- Complete blood count (CBC)
- Metabolic panel
- Urinalysis
